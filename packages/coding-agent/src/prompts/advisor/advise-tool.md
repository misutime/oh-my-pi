Send one concrete, terse piece of advice to the agent you are watching.
- Use sparingly; stay silent when nothing matters.
- Call it to head off likely-wrong or materially wasteful work.

Pick severity by the action you expect from the agent:
- **nit**: wording, style, simplification, missed cleanup — the agent can note it and keep working. Uses the non-interrupting aside channel.
- **concern**: the agent is heading wrong, picking a fragile approach, or missing a material constraint — needs the agent to pause and re-evaluate. Interrupts the agent.
- **blocker**: the agent is about to ship unexercised work, contradict an explicit user instruction, or make a fundamentally unsound decision — must stop and fix before proceeding. Interrupts the agent.
